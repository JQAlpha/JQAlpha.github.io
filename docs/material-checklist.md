## 附：还需要你在别处操作的 3 件事（不是素材，但会影响上线）

这三件我做不了，需要你手动：

1. **建仓库后的页面设置**（约 30 秒）
   仓库 Settings → Pages → Build and deployment → Source 选 **GitHub Actions** → Save
   （这一步必须手动，GitHub Actions 的内置令牌没有创建 Pages 站点的权限）

2. **DNS 记录**（在阿里云 DNS 控制台，约 2 分钟）
   ```
   主机记录  类型     记录值
   @          A        185.199.108.153
   @          A        185.199.109.153
   @          A        185.199.110.153
   @          A        185.199.111.153
   www        CNAME    JQAlpha.github.io
   ```
   注意：现有的 MX 和 TXT(SPF) 记录**不要动**，那是邮箱在用的

3. **域名所有权验证**（可选但建议，防止域名被别人抢注挂到他们的 Pages 上）
   GitHub 个人 Settings → Pages → 添加域 → 填 jqalpha.com → 拿到随机串后
   在阿里云加一条 TXT：主机记录 `_github-pages-challenge-JQAlpha`，记录值填那个随机串
